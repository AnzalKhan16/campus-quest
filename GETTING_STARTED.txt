🚀 QUICK START (5 MINUTES):
─────────────────────────────────────────────────────────────────────────────

1. Make sure MongoDB is running
   • Open Services (Win + R → services.msc)
   • Find "MongoDB Server" → Start

2. Open this folder in VS Code
   • File → Open Folder → select campus-quest-backend

3. Open Terminal in VS Code (Ctrl + backtick)

4. Type this command and wait 3-5 minutes:
   mvn clean install

5. Then start the server:
   mvn spring-boot:run

6. When you see "Started CampusQuestApplication" → SUCCESS! ✅

7. Test it works (new terminal tab):
   curl http://localhost:8080/api/courses

   Should return: []

🎯 WHAT GETS CREATED:
─────────────────────────────────────────────────────────────────────────────

Database (MongoDB on localhost:27017):
  Users Collection .............. user accounts with XP, level, streak
  Courses Collection ............ available courses
  User Progress Collection ...... course enrollment & completion
  Badges Collection ............. achievements earned

API Server (Java on localhost:8080):
  Handles login/register ......... /api/auth/login, /register
  Manages user profiles .......... /api/users/profile
  Serves courses ................. /api/courses
  Calculates leaderboard ......... /api/leaderboard/weekly

─────────────────────────────────────────────────────────────────────────────

📊 ARCHITECTURE:
─────────────────────────────────────────────────────────────────────────────

Request Flow:
  
  Client (React)
      ↓
  API Endpoint (/api/users/profile) → UserController
      ↓
  Business Logic → UserService
      ↓
  Database Query → UserRepository
      ↓
  MongoDB ← Store/Retrieve User Data
      ↓
  Response JSON → Client

─────────────────────────────────────────────────────────────────────────────

🔑 KEY ENDPOINTS:
─────────────────────────────────────────────────────────────────────────────

POST   /api/auth/register          Register new user
POST   /api/auth/login             Login user (get JWT token)
GET    /api/users/profile          Get user profile (requires token)
GET    /api/courses                Get all courses
POST   /api/courses/{id}/enroll    Enroll in course
GET    /api/leaderboard/weekly     Get top 10 users
GET    /api/leaderboard/rank       Get your rank

💡 TESTING THE API:
─────────────────────────────────────────────────────────────────────────────

Option A: Thunder Client (VS Code extension) - EASIEST
  • Install "Thunder Client" in VS Code
  • Create new request: POST /api/auth/register
  • Send JSON: { "email": "test@test.com", "password": "123", "fullName": "Test" }

Option B: Postman (standalone app)
  • Download from postman.com
  • Same as Thunder Client but more features

Option C: Command line (curl)
  • curl -X POST http://localhost:8080/api/auth/register \
    -H "Content-Type: application/json" \
    -d '{"email":"test@test.com","password":"123","fullName":"Test"}'

❓ COMMON ISSUES:
─────────────────────────────────────────────────────────────────────────────

"Connection refused"
  → MongoDB not running. Open services.msc and start MongoDB Server

"Port 8080 already in use"
  → Change port in application.yml (line 12) from 8080 to 8081

"BUILD FAILURE"
  → Run: mvn clean install -U

Lots of red text in terminal
  → Scroll down. If it says "BUILD SUCCESS" at the end, you're fine.
